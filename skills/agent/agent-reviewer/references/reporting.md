# Review Reporting Contract

Specifications for review reports generated by `agent-reviewer`.

## Filtering Discipline

Report only **Critical** (🔴) and **Important** (🟡) findings.
- **Critical (🔴):** Functional bugs, security vulnerabilities, missing tests for new logic, or data-loss risks.
- **Important (🟡):** Performance regressions, unhandled edge cases, brittle tests, or contract violations.
- Discard minor suggestions or cosmetic nits.

## Anchoring and Suggestions

- **Accurate line anchoring:** Use the new-file line number from the `awk` annotated diff.
- **GitHub suggestion blocks:** Provide drop-in replacement suggestions using standard GitHub markdown:
  ````markdown
  ```suggestion
  const total = items.reduce((acc, item) => acc + item.price, 0);
  ```
  ````
- **Concise technical English:** Write explanations using ASD-STE100 principles (active voice, short sentences, explicit root-cause analysis).
