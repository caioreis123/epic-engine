# Agent Reviewer

## Overview

Spawns an author-blind review agent in a **split pane directly above the caller** in the same Herdr tab. The reviewer executes an exhaustive correctness and quality checklist against the PR diff and reports findings directly to a designated report file, notifying the caller upon completion.

```
┌─────────────────────────────────┐
│ Reviewer Pane (agent-reviewer)  │  ← Frontier reasoning model, fresh author-blind context
├─────────────────────────────────┤
│ Caller Pane (agent-executor)    │  ← $HERDR_PANE_ID (return address)
└─────────────────────────────────┘
```

## Why This Architecture Works

1. **Topological Co-location (`herdr pane split` + `pane swap`):** Placing the reviewer above the worker keeps context visible in the same tab while preserving the caller's pane ID for asynchronous callback.
2. **Author-Blind Independence:** Self-review by the author session suffers from confirmation bias and polluted context. Spawning a fresh session with an isolated context window ensures critical defects are surfaced objectively.
3. **Frontier Model Reasoning (`reviewer` in `models.json`):** Implementation is executed on high-throughput models (`worker`), while review runs on frontier reasoning models (`reviewer`) to catch subtle logic errors and edge cases.
4. **AWK Line-Annotated Diff:** Reviewers evaluate line-numbered diffs generated by the AWK annotator ([references/awk-diff-annotator.md](references/awk-diff-annotator.md)), ensuring comment anchors never drift.

## Dispatching the Reviewer

```bash
skills/agent/agent-reviewer/agent-reviewer.sh <pr-url-or-number>
```

The script splits the pane, moves the reviewer above the caller, starts the agent session, and delivers the review assignment.

## Review Checklists

- **[references/correctness.md](references/correctness.md):** Both sides of equality comparisons, conditional logic permutations, unhandled promise rejections, magic literals, and contract boundaries.
- **[references/quality.md](references/quality.md):** Test coverage gap audits for new logic, integration testing of changed contracts, and comment/docstring accuracy.
- **[references/reporting.md](references/reporting.md):** Output format, filtering out minor nits, and formatting GitHub suggestion blocks.
