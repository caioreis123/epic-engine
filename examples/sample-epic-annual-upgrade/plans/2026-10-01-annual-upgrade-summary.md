# Plan Summary: Annual Plan Upgrade Popover

## Delivery Overview

Delivers an annual upgrade modal across three participating repositories following the Integration PR Model.

- **`acme/graphql-bff`:** Single integration PR on branch `epic/annual-upgrade`. Contains `task-1`.
- **`acme/web-app`:** Single integration PR on branch `epic/annual-upgrade`. Contains `task-2` and `task-3` sequentially.
- **`acme/visual-check`:** Single integration PR on branch `epic/annual-upgrade`. Contains `task-4` executed after upstream PRs stabilize.

## Risk & Dependency Boundaries

1. Upstream schema dependency: `web-app` relies on `AnnualUpgradeOffer` type generated by `graphql-bff`.
2. Telemetry validation: events will be cross-referenced with `analytics_prod.experiment_events`.
3. Minimal mocking: `visual-check` uses real test user IDs `100001` and `100002`.
